# The Solar-Magnetosphere-Ionosphere eXplorer (SOMIX)

## Scientific Goal

This tool aims to collect and visualize data from various satellite missions related to space weather. In particular, missions focusing on the Sun, Earth's magnetosphere and the ionosphere are considered. Timeseries data will be provided on a dashboard to make intercomparisson easy. Furthermore, preselected timestamps for geomagnetic storms will be provided to quickly access the data. If in line with the data suppliers, the data from the dashboard is provided as .txt file from the dashboard. In the long run, a Python library will be set up to make the data available for individual analysis.

### Instruments

The Sun:

- ACE
- GOES

Magnetosphere

- Swarm
- MMS
